## MODIFICHE APPORTATE

### P0.5-A — I18N Contract Fix (`/app/backend/routers/blueprint.py`)

**Root cause:** `BLUEPRINT_OPERATIONAL_LOCALES` usava short codes (`it`, `fr`, `de`, `es`) per le lingue europee non-inglesi, mentre il frontend invia sempre BCP-47 full codes (`it-IT`, `fr-FR`, `de-DE`, `es-ES`). Solo `en-US` e `en-GB` funzionavano.

**Fix applicato:**
```python
# PRIMA
BLUEPRINT_OPERATIONAL_LOCALES = frozenset({"it", "en-US", "en-GB", "fr", "de", "es"})

# DOPO
BLUEPRINT_OPERATIONAL_LOCALES = frozenset({
    # Full BCP-47 (canonical — frontend sends these)
    "it-IT", "en-US", "en-GB", "fr-FR", "de-DE", "es-ES", "es-MX",
    # Short forms (backward compat — legacy data / CLI tests)
    "it", "fr", "de", "es",
})
```

**Effetto:**
- Eliminata la 403 su `blueprint/i18n/it-IT` che bloccava l'intera app
- La Welcome page ora si avvia correttamente (passa dallo spinner globale al loading di pagina)
- Tutte le lingue europee gestite

### P0.5-B — Lifecycle Propagation Fix (`/app/backend/routers/journey_initiate.py`)

**Root cause:** Dopo la creazione del journey, i layer CRM non venivano aggiornati:
- `leads.progression_state` restava `lead`
- `leads.first_journey_id` restava NULL
- `leads.intake_completed_at` restava NULL
- `accounts.lifecycle_stage` restava `prospect`

**Fix applicato — Lead update (dopo INSERT):**
```python
c.table("leads").update({
    "status":             "qualified",
    "pipeline_stage":     "prospect_initial_brief",
    "progression_state":  "prospect",       # ← AGGIUNTO
    "first_journey_id":   journey_id,       # ← AGGIUNTO
    "intake_completed_at": now,             # ← AGGIUNTO
    "updated_at":         now,
}).eq("id", lead_id).execute()
```

**Fix applicato — Account advancement (post-provisioning):**
```python
c.table("accounts").update({
    "lifecycle_stage": "active",            # ← AGGIUNTO
    "updated_at":      now,
}).eq("id", account_id).execute()
```

**Nota:** Primo tentativo usava `"progression_state": "qualified"` — violava constraint DB. Corretto a `"prospect"` (unico valore valido diverso da `"lead"`).
